- 기능 미확인·명시적 미지원·상충 근거 구분, 전체 사양 diff·숫자·표·양쪽 인용 검증
- 분석 작업 취소·재개, 일반 질문과 생성 대기열 공유
- 기존 DB 사전 백업, 과거 추출 텍스트 표시, 실제 원문으로 재동기화

실제 모델 smoke 테스트는 기본 테스트와 분리했습니다. 기존 `tests/live-smoke.ts`는 실행 중인 Nexa에 예제 자료를 등록하고 `data/live-smoke-results.json`에 기록합니다. 새 버전 테스트는 아래처럼 명시적으로 실행하며 JSON 결과를 표준 출력으로 내보냅니다.

```powershell
$env:NEXA_LIVE_VERSION_SMOKE = '1'
.\.runtime\bun\bun.exe --no-install tests/version-live-smoke.ts
Remove-Item Env:NEXA_LIVE_VERSION_SMOKE
```

## 기존 화면·운영 검증 기록

- 실제 브라우저에서 한국어 답변, 보드 필터, 코드 검색, 원문 줄 강조, 자료·작업 목록, 관리자 키 누락 오류를 확인했습니다. 요청 취소 후 입력도 정상 복구됐습니다.
- 데스크톱·390px 화면을 시각적으로 확인했고 320px에서도 가로 넘침이 없었습니다. 브라우저 콘솔 오류·경고는 0개였습니다. 인증된 업로드·삭제는 HTTP 통합 테스트로 검증했습니다.
- 모델·Qdrant·API 종료 후 다시 실행해 소스 2개·문서 5개·청크 6개와 벡터가 유지됨을 확인했습니다. 재시작 후 실제 질의 6개도 통과했습니다.
- 별도 포트에서 `-NoModels` 실행, API 키 인증, 중복 실행 방지, 종료를 확인했습니다.
- PowerShell 7의 JSON 날짜 변환으로 발생한 프로세스 소유권 비교 오류를 수정했습니다. `scripts/test-process-ownership.ps1`은 PowerShell 5.1과 7에서 정확한 시작 시각, 실행 경로, 확인되지 않은 프로세스의 기록 보존을 검사합니다.
