# ATLAS Rev A UART console

This is a synthetic example for Nexa development, not a real board specification.

Board: ATLAS
Revision: A
The debug console uses UART0, baud rate 115200, 8 data bits, no parity, 1 stop bit (8N1).
Pins: TX = PA9, RX = PA10.
Do not connect a 5 V signal to the UART pins; the I/O voltage is 3.3 V.
